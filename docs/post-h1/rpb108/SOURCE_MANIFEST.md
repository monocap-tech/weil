## Reproducibility and custody gate

Before promoting any provisional RPB-P result as a trusted public theorem, a reviewer should:

1. Fetch immutable upstream commits and record SHA256 of all decompressed native source archives, target rational vectors, producer scripts, validator scripts, and certificate data.
2. Replay original signed archimedean + prime + pole source construction, including both translation orientations, endpoint logarithms, all sector cross terms, and complete retained physical projection.
3. Check every published interval's outward error budget: rational/transcendental constants, truncation remainder, projection rounding, inverse enclosure, positive physical-mass conversion, and native matrix interval pivots.
4. Verify analytic form-domain and source pairing assumptions separately from Python's rational arithmetic.
5. Replay positive/null/negative controls and distinguish actual Weil conclusions from abstract estimator sharpness models.
6. Record the reproducible environment and reproducibility results; the present dossier's upstream citations are **not** a fresh replay.
